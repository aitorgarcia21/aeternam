# Polices du site

Les fichiers WOFF2 sont servis localement, sous licence SIL Open Font License 1.1. Les licences originales accompagnent les fichiers.

- Newsreader, romain et italique variables (graisses 400–600, tailles optiques 6–72) : [projet original](https://github.com/productiontype/Newsreader), [distribution Google Fonts](https://github.com/google/fonts/tree/main/ofl/newsreader).
- DM Sans, romain variable (graisses 400–600) : [projet original](https://github.com/googlefonts/dm-fonts), [distribution Google Fonts](https://github.com/google/fonts/tree/main/ofl/dmsans).

Sous-ensembles latin et latin étendu récupérés auprès de `fonts.gstatic.com` via la feuille de styles Google Fonts le 8 octobre 2026. `site/style.css` conserve les plages Unicode correspondantes et utilise `font-display: swap`. Aucune requête Google Fonts n'est effectuée par les pages du site.
